# Marker lettering source

The font source is Annie Use Your Telescope by Kimberly Geswein.
It contains outlines from a real handwriting sample.
The SIL Open Font License permits its use and modification.
The license is in `public/fonts/OFL.txt`.

Source: [Google Fonts](https://github.com/google/fonts/tree/df8d76c2fac61408089902771074a75d875aca1f/ofl/annieuseyourtelescope).

The font builder preserves the source curves, adjusts the tall `l`, and adds spacing pairs for the site text.
It packages these changes as Marco Marker.
The reference photo guides the proportions and spacing. The font is a handwriting derivative, not a direct trace of the photo.
